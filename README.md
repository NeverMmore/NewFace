# NewFace 世界书新角色

SillyTavern（酒馆）UI 扩展：根据**当前角色卡绑定的世界书**，生成一个**全新原创角色**的 SFW 资料和 NSFW 资料。

## 解决什么问题

直接让 AI "在这个世界里创造一个新角色"时，它经常把世界书里已有、只是还没出场的人物拿来用：直接写成那个人、换个名字套用，或者在新角色的关系里写满已有人物。NewFace 从三个方面防止这种情况：

1. **人物条目不发全文**：世界书条目会自动分成「人物」和「设定」两类。设定条目作为世界观资料发给 AI；人物条目只把名字（和一句身份简介）放进**禁用名单**，不把完整资料发出去，AI 就没有可以照抄的人。
2. **遮蔽设定资料里的人名**：设定条目里提到的已有人名（如"宗主林晚坐镇青云峰"）会替换成「〔某已有人物〕」，AI 没法从设定资料里找到这些人。
3. **生成后检查并自动修正**：扫描结果里有没有出现名单上的人、新角色是否与已有人物（包括 {{char}}、{{user}}）重名或名字太像。发现问题就把原文和问题一起发回给 AI 修改（次数可设置），状态栏会显示检查结果。

如果你**确实想让**新角色和某个已有人物有关系，在条目列表里勾选该人物的「允许提及」，这个人的完整资料就会发给 AI，检查时也不会报错。

## 资料格式

生成的资料是 YAML 风格的结构化格式，整份用 `<姓名>` 标签包裹，可以直接放进世界书或角色卡：

```
<姓名>
  基本信息:        姓名 / 年龄 / 性别 / 身份 / 与{{user}}关系
  外貌特征:        形象概述 / 身高 / 体重 / 三围 / 体型 / 罩杯 / 脸型 / 肤色 / 五官 / 发型
  女性NSFW设定:    （男性角色为「男性NSFW设定」）
    身体细节:            胸部 / 性器 / 臀部等
    性经验与偏好:        性取向 / 性经验 / 性观念 / 敏感带 / 性癖 / 雷区与底线 / 自慰习惯 / 性幻想
    亲密时的反差:        与日常性格不一样的地方
    发展亲密关系的契机:  什么情境下才可能和{{user}}走到这一步
  背景设定:        经历轨迹、来到当前处境的始末
  关系设定:        互动起点 / 互动机制
  性格架构:
    底层认知-防备机制:   特质 → 内在信念 + 行为表现
    显性性格-日常做派:   特质 → 内在信念 + 行为表现
    应激反差-受挫状态:   特质 → 内在信念 + 行为表现
  二次解释:        关于“某特质”：划清边界，防止扮演时演歪
</姓名>
```

SFW 部分和 NSFW 部分分两次生成（NSFW 以 SFW 资料为准），复制 / 写入世界书 / 新建角色卡时会自动把 NSFW 块插到「外貌特征」后面，合成一整份。NSFW 模板按资料里的「性别」自动选男 / 女版本。

## 使用

1. 打开一个**单人角色**的对话（群聊不支持）。
2. 魔杖菜单 →「世界书新角色」，或输入 `/newface`（`/新角色`），或在扩展设置面板里点「打开」。
3. **① 世界书**：已自动勾选这个角色的主世界书、附加世界书和当前聊天绑定的世界书；卡内嵌的 character_book 也能读取。还可以手动添加其他世界书（会按角色记住）。
4. **② 条目分类**：检查自动分类，不准的就手动改成 人物 / 设定 / 忽略（会记住）。禁用名单可以展开后手动编辑，每行一个人物，用 `|` 分隔别名。
5. **③ 需求**：填写性别、年龄、定位和其他要求，选择「SFW + NSFW」或「只生成 SFW」，点「生成」。「预览提示词」可以看实际发给 AI 的内容。
6. **④ 结果**：两栏都可以直接编辑；🎲 是重新生成（NSFW 以上面的 SFW 资料为准）；「修正」手动触发一次修正。完成后可以：
   - **复制全部**
   - **写入世界书**：作为新条目「人物 - 名字」写入所选世界书，关键词是新角色的名字。之后再生成时，这个人也会进入禁用名单。
   - **新建角色卡**：用资料新建一张角色卡，并绑定同一本世界书。
   - 最近 30 条结果保存在「历史记录」下拉框里。

## 设置（右上角齿轮）

- 接口：酒馆当前连接 / 酒馆连接配置档（Connection Profile）
- 设定资料字数上限（默认 12000 字；常驻条目优先）
- 自动修正次数（默认 2）
- SFW 资料模板、NSFW 模板（女性 / 男性各一份）、系统提示词，都可以修改，也可以一键恢复默认。模板里（…）是给 AI 的填写说明，`<…>` 是让 AI 自己起名的小标题
- 升级插件时，没改过的模板会自动换成新版；改过的模板保持不动，并弹一次提示（需要新字段可以点「恢复默认模板与提示词」）
- 资料比较长（两三千字），用「酒馆当前连接」时请把酒馆的「最大回复长度」设到 4000 token 以上，否则会被截断；连接配置档模式默认 8192

## 说明

- 所有生成的角色都要求是成年人（18 岁及以上），提示词里要求写明具体年龄。
- 自动分类靠标题和内容里的关键字（如"角色/人物"、"性别：""年龄："等）判断，分错了手动改一下就行。

## 安装

在酒馆的「扩展」面板点「安装扩展」，填入：

```
https://github.com/NeverMmore/NewFace
```

或者手动把 `NewFace` 文件夹放到 `SillyTavern/public/scripts/extensions/third-party/` 下，然后刷新酒馆。

## 开发

```bash
npm test
```

`tests/browser/harness.html` 是带模拟酒馆上下文的测试页，在 `NewFace` 目录下启动一个静态服务器后打开即可。
